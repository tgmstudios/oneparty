# Repository agent instructions

For this Dawghouse event, every custom scene must visibly say **DAWGHOUSE** as part of its own 3D artwork and visibly respond to the music. Put the name on a diegetic sign, object, or environmental feature designed for that scene. Never add a fixed screen-space/camera-locked logo, corner bug, HUD watermark, or display badge. Give at least one prominent object or environmental feature a clear beat or bass response through `music(t)`. Make scenes visually distinctive and detailed rather than reusing the same layout.

See [`docs/AGENT.md`](docs/AGENT.md) for the operator workflow and scene authoring guidance. Claude-specific guidance is in [`CLAUDE.md`](CLAUDE.md).
